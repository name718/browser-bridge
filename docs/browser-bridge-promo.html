它能做什么

把本地 Agent 从“只能读代码和发 HTTP 请求”扩展到“能看见并操作你的真实浏览器页面”。

读

读取有权限页面

读取当前标签页、指定 URL、页面文本、链接、可操作元素和截图，适合 Cooper、内部后台、登录态系统。

点

操作页面元素

按文本、选择器、role、placeholder、aria-label、elementId 点击按钮、切换菜单、清空和输入表单。

跑

执行结构化步骤

通过 `browser_run_steps` 一次发送多步操作，按顺序执行并返回每一步结果，适合沉淀可复用流程。

截

截图辅助调试

支持可视区域截图和失败截图元信息，复杂页面可以让 Agent 结合 DOM 与画面判断下一步。

守

安全边界内执行

域名允许列表、拒绝列表、高风险点击确认、审计日志，让 Agent 不必拿到 Cookie 也能完成任务。

接

接入多类 Agent

通过 MCP stdio 接入 Claude Code、Codex、Gemini CLI 等本地 Agent，插件与 daemon 可长期复用。

工作原理

Agent 不直接访问网站，不读取浏览器 Cookie。它只调用本地 MCP，实际页面读取和操作由 Chrome 插件在用户浏览器内完成。

AI Agent Claude Code、Codex、Gemini CLI 生成工具调用或结构化步骤。
MCP Server 暴露 browser_status、browser_run_steps、browser_screenshot 等工具。
本地 Daemon 监听 17320 HTTP API 和 17321 WebSocket 桥接端口。
Chrome 插件 用用户登录态读取页面、执行点击输入、回传结果和截图。

怎么使用

常规对话中可以让 Agent 自己组织步骤；需要稳定复用时，直接给 `browser_run_steps` JSON。

{
  "steps": [
    {
      "action": "open",
      "url": "https://example.com"
    },
    {
      "action": "waitFor",
      "text": "Example Domain",
      "timeoutMs": 5000
    },
    {
      "action": "getText"
    }
  ],
  "stopOnError": true,
  "screenshotOnError": true
}
1
重新加载插件在 `chrome://extensions` 加载 `packages/extension/dist`，弹窗显示 `已连接 / OPEN`。
2
配置 MCP 客户端Claude Code、Codex 或 Gemini CLI 指向 `packages/mcp-server/dist/index.js`。
3
发起自然语言任务例如“打开这个页面，点击账号菜单，读取当前页面主要信息”。
4
沉淀结构化脚本把高频流程保存成 JSON 步骤，后续让 Agent 直接复用。

怎么提高开发效率

让 Agent 能在真实系统里验证需求、检查页面、执行后台操作，把“人工打开浏览器确认”的环节自动化。

需求理解更快

  • 直接读取 Cooper、PRD、内部知识库页面。
  • 不需要复制粘贴长文档给 Agent。
  • Agent 可以基于当前页面内容生成技术方案和任务拆解。

联调验证更稳

  • 打开测试环境，读取页面状态，截图定位问题。
  • 按菜单路径进入后台页面，减少重复点击。
  • 失败时返回具体步骤和错误码，便于复现。

后台操作可复用

  • 把登录、切菜单、查询订单、打开详情沉淀成步骤。
  • 同一套步骤可被 Claude Code、Codex、Gemini CLI 调用。
  • 结构化步骤比临时 UI 自动化脚本更容易审计。

安全边界更清晰

  • Agent 不拿 Cookie，不直接请求内部站点。
  • 删除、审批、支付、提交等高风险动作需要确认。
  • 插件保留操作审计，方便排查 Agent 做过什么。

安全不是附加功能

Browser Bridge 的核心原则是“让 Agent 操作浏览器，但不把浏览器完全交给 Agent”。

不执行任意 JS使用结构化步骤，插件只执行内置动作。
域名白名单只允许配置范围内的网站被读取和操作。
高风险确认提交、删除、审批、支付等动作弹出页面确认。
审计日志记录工具、URL、结果和错误码。

把 Agent 接进真实浏览器工作流

适合内部后台、权限网站、知识库、测试环境和需要人工登录态的页面操作。先从读取页面和结构化步骤开始，再逐步沉淀团队专属浏览器自动化流程。
